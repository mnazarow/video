# CorpVideo и популярные видеохостинги: что взято за основу

Обзор функций популярных публичных и корпоративных видеоплатформ (сентябрь 2026) и их отражение в CorpVideo. Документ состоит из четырёх частей: первая (версия 1.1) — YouTube и корпоративные платформы «первого круга», вторая (версия 1.2) — западные корпоративные и маркетинговые, российские, азиатские, стриминговые платформы и инструменты согласования видео, третья (версия 1.3) — видео-API для разработчиков, системы обучения (LMS), инструменты монтажа, онлайн-кинотеатры, стриминг второго эшелона и подкасты, четвёртая (версия 1.4) — платформы онлайн-курсов, медиасерверы для самостоятельного размещения, видео внутри рабочих инструментов, инструменты интерактивного видео и требования доступности.

## Часть 1. Что характерно для каждой платформы (версия 1.1)

Источники — официальные страницы продуктов и справочные центры: Microsoft Stream (on SharePoint), Panopto, Kaltura, Vimeo (Enterprise, review links), Wistia, Loom (Atlassian), VK Видео, RUTUBE, PeerTube.

| Платформа | Профиль | Характерные функции |
|---|---|---|
| **YouTube** | публичный хостинг | каналы, подписки, плейлисты, «Shorts», главы, раскадровка, субтитры и транскрипт, комментарии с таймкодами, тренды, рекомендации, эфиры с чатом, аналитика удержания, горячие клавиши, мини-плеер, «картинка в картинке», встраивание |
| **Microsoft Stream (SharePoint)** | корпоративный, внутри M365 | права на видео как на файлы (группы, сайты), запись экрана в браузере (Clipchamp), транскрипт и поиск по нему, главы, комментарии, плейлисты, Copilot-конспекты, политики хранения и аудит, интеграция с Teams |
| **Panopto** | обучение и корпоративные библиотеки | тесты внутри видео с остановкой воспроизведения, обсуждения с таймкодами, заметки и закладки зрителя, поиск внутри видео (речь + слайды), процент завершения по каждому зрителю, «кто посмотрел», тепловые карты пересмотров, выгружаемые отчёты о прохождении, интеграция с LMS |
| **Kaltura MediaSpace** | корпоративный портал | каналы и категории, собственный рекордер экрана и камеры, тесты и интерактивные ветвления, ИИ-конспекты и клипы, OCR/ASR-поиск, субтитры и дубляж, главы, расширенная аналитика, брендирование |
| **Vimeo (Enterprise)** | профессиональный хостинг | пять уровней приватности, ссылки с паролем и сроком действия, ограничение доменов для встраивания, страницы согласования с заметками по таймкодам и версиями файла, замена видео с сохранением ссылки, SSO/SCIM, витрины (showcase) |
| **Wistia** | видеомаркетинг | настраиваемый плеер под бренд, призывы к действию и формы внутри видео, тепловые карты просмотра по каждому зрителю, галереи-«каналы», SEO, обрезка, вебинары |
| **Loom** | асинхронные сообщения | мгновенная запись экрана и камеры, авто-название/конспект/главы по транскрипту, удаление пауз и слов-паразитов, реакции и комментарии, статистика «кто и сколько посмотрел» |
| **VK Видео / RUTUBE** | российские публичные | клипы (вертикальные), ИИ-поиск и авто-субтитры, распознавание речи, рекомендации, эфиры, монетизация коротких видео |
| **PeerTube / MediaCMS** | открытые самостоятельные | импорт видео по ссылке, несколько каналов у пользователя, студия (обрезка, водяной знак), повторы эфиров, версии видео, квоты, плагины и темы, LDAP/OIDC |

| Установка как приложение (PWA), иконка на рабочем столе | Stream, Kaltura Go | добавлено в 1.1: манифест PWA, service worker, пункт «Установить приложение» в меню |
| Реакции-эмодзи, монетизация, донаты, федерация, дубляж ИИ | Loom, RUTUBE, PeerTube, Kaltura | не планируется для внутреннего портала |

### Матрица функций 1.2 и решения для CorpVideo

| Функция | Где встречается | CorpVideo 1.2 |
|---|---|---|
| **Единый вход (SSO)** через OpenID Connect: Keycloak, ADFS, Яндекс ID, Google, Okta | все корпоративные платформы (Vbrick, VIDIZMO, Mediasite, Brightcove, Kinescope) | добавлено: вход через OIDC (Authorization Code + PKCE, проверка подписи ID-токена по JWKS), автоодобрение и проверка домена, синхронизация групп из claim, «только SSO» |
| **Срок публикации** видео (снять с публикации автоматически) | Vbrick (expiration), Dailymotion (end date) | добавлено: поле «Снять с публикации» в студии; по истечении видео становится приватным, автору приходит уведомление |
| **Ограничение доменов встраивания** | Vimeo, Dailymotion, Kinescope, Boomstream | добавлено: список разрешённых доменов в настройках → `Content-Security-Policy: frame-ancestors` для страниц `/embed/` |
| **Материалы к видео** — презентации, PDF, чек-листы | Kinescope (вложения), Coursera, Mediasite | добавлено: вкладка «Материалы» в студии, блок скачивания на странице просмотра, счётчик скачиваний, доступ как у видео |
| **Опросы и вопросы к ведущему** во время эфира | Vbrick, Boomstream, Zoom/Teams, Twitch | добавлено: панель «Вопросы и опросы» в эфире (голосование, анонимные вопросы, ответы ведущего, экспорт вопросов CSV), управление из студии эфира |
| **Напоминание о запланированном эфире**, файл календаря | Zoom/Teams, YouTube «Напомнить», Coursera | добавлено: кнопка «Напомнить» (уведомление за 15 минут и в момент начала), «В календарь» (.ics), .ics для назначений со сроком |
| **Сертификат о прохождении** с номером и проверкой | Coursera/LMS, Kaltura (через LMS) | добавлено: опция в назначении, автоматическая выдача после просмотра и теста, страница для печати `/cert/<id>`, «Мои сертификаты», отзыв, CSV по назначению |
| **Контроль присутствия** («Вы ещё смотрите?») | Boomstream, LMS | добавлено: периодическая пауза с подтверждением в назначениях (каждые 3–15 минут), пока сотрудник не подтвердит |
| **Вертикальная лента коротких видео** со свайпом | TikTok, YouTube Shorts, VK Клипы | добавлено: страница «Короткие» в виде вертикальной ленты (свайп, клавиши ↑/↓, лайк, комментарии, подписка, звук) и адаптация под телефон |
| **Скачивание транскрипта** (TXT/SRT/VTT/JSON) | Zoom/Teams, Stream, Panopto | добавлено: меню «Транскрипт» на странице просмотра и API `/api/videos/:id/transcript` |
| **Уведомления в мессенджер** | Vidyard (Slack), Loom, Teams-платформы | добавлено: Telegram-бот (привязка аккаунта командой `/start <код>`, выбор типов уведомлений), long polling без внешнего адреса |
| **Вложенные группы AD** | Stream (M365), VIDIZMO | добавлено: опция «Вложенные группы» в настройках LDAP (оператор `LDAP_MATCHING_RULE_IN_CHAIN`) |
| **База знаний / RAG**: документы из видео для корпоративного ИИ | Stream Copilot, Kaltura, VIDIZMO smart search | добавлено: документы (Markdown/JSON) из названия, описания, глав, материалов и транскрипта; отправка во внешний RAG-сервис (push), API для выгрузки (pull) с отдельным токеном, описание документов через стороннюю LLM |
| **ИИ-описание всех видео** через стороннюю LLM | Loom, Stream Copilot | добавлено: «Описать все видео» в интеграциях (очередь ИИ-обогащения), автоописание новых видео |
| Комментарии «данмаку» поверх видео, GIF-реакции, предсказания | Bilibili, Twitch | не планируется: не соответствует корпоративному стилю |
| DRM (Widevine/FairPlay), форензик-водяной знак, eCDN/P2P | Kinescope, Frame.io, Vbrick | возможное развитие; пока — водяной знак зрителя, защищённые ссылки, домены встраивания |
| Редактирование персональных данных в кадре, ИИ-аватары, CRM | VIDIZMO, Vidyard | не планируется для внутреннего портала |

## Часть 3. Видео-API, LMS, стриминг и онлайн-кинотеатры (версия 1.3)

В третьей итерации изучены платформы, которые обычно остаются за рамками сравнения «видеохостингов», но задают ожидания интеграторов и пользователей: видео-API для разработчиков (Mux, Cloudflare Stream, Bunny Stream, api.video), системы обучения (iSpring Learn, WebTutor, Mirapolis, Эквио, Moodle), инструменты монтажа (Descript), онлайн-кинотеатры (Кинопоиск, Netflix), стриминговые сервисы второго эшелона (Kick, Rumble, Trovo), российские социальные видеоплатформы (OK Video, Дзен) и экосистема подкастов/RSS.

| Платформа | Профиль | Характерные функции |
|---|---|---|
| **Mux / Cloudflare Stream / Bunny Stream / api.video** | видео-API для разработчиков | **вебхуки** о готовности и ошибках с подписью, подписанные URL и токены воспроизведения, прямая загрузка (tus/UpChunk), автосубтитры, миниатюры и раскадровки, **клипы (clipping)**, симулкаст эфиров, **Player SDK** (web-компонент, события, команды), аналитика по сеансам (Mux Data) |
