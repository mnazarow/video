# CorpVideo — корпоративный видеохостинг

Внутренний видеопортал компании в духе YouTube: загрузка и просмотр видео, каналы, подписки, плейлисты, комментарии, поиск, прямые трансляции с чатом, автосубтитры, аналитика — и панель администратора с модерацией, регистрацией сотрудников только с одобрения администратора и только с корпоративных доменов почты. Дизайн выполнен в стиле [vodokomfort.ru](https://vodokomfort.ru) (фирменный синий #0F4382, заголовки DIN Condensed, текст Roboto).

Устанавливается на чистый сервер Linux одной командой (Docker Compose или нативно на Ubuntu/Debian), обновляется и удаляется одной командой.

## Возможности

**Для зрителей**
- Главная с персональными разделами (подписки, продолжить просмотр, тренды, категории), «Короткие», страницы категорий и тегов.
- Плеер с адаптивным качеством (HLS 240p–2160p), выбором качества и скорости, главами, раскадровкой при наведении на прогресс, субтитрами и панелью транскрипта с поиском по тексту, горячими клавишами (подсказка по `?`), мини-плеером, театральным и полноэкранным режимом, «картинка в картинке», автовоспроизведением следующего; анимированное превью видео при наведении на карточку.
- Полнотекстовый поиск (русская морфология, без учёта регистра и диакритики) по видео, каналам и плейлистам, подсказки, история запросов, фильтры и сортировка.
- Лайки, комментарии с ответами, закреплением и модерацией автора; подписки на каналы с уведомлениями; «Смотреть позже», понравившиеся, история просмотров, плейлисты; уведомления в реальном времени (WebSocket); светлая и тёмная темы; адаптивная вёрстка для телефона.
- Общий доступ: ссылка с таймкодом, **ссылка на фрагмент** (с … по …), код встраивания (embed), QR-код, скачивание оригинала (если разрешено автором).
- **Назначено мне**: обязательные к просмотру видео и курсы (плейлисты) со сроками, прогрессом и напоминаниями; раздел на главной и счётчик в меню.
- **Проверка знаний**: вопросы по ходу видео (с паузой) и итоговый тест с проходным баллом, пояснениями и повторными попытками.
- **Личные заметки** с таймкодами прямо на странице видео (панель «Заметки»), страница «Мои заметки», экспорт в Markdown.
- Приложение можно **установить на телефон и компьютер (PWA)**: значок на рабочем столе, ярлыки «Назначено мне» и «Загрузить».
- **Вертикальная лента коротких видео** (свайп, клавиши ↑/↓, лайк, комментарии, подписка, звук) — как YouTube Shorts / TikTok.
- **Материалы к видео** (презентации, PDF, чек-листы) и **скачивание транскрипта** (TXT/SRT/VTT).
- **Сертификаты о прохождении** обязательных курсов: именной сертификат с номером, страница для печати и проверки, раздел «Сертификаты».
- **Курсы** (1.4): учебные программы из видео, материалов и пояснений по разделам, последовательное прохождение, прогресс, сертификат; лента курса над плеером.
- **Реакции по таймкоду и тепловая карта** «часто пересматривают» (1.4); **переход к найденному моменту** из поиска; **«Пропустить вступление»**.
- **Доступность** (1.4): дубляж и тифлокомментарий отдельными звуковыми дорожками, настройка размера субтитров и подложки, режим повышенной контрастности, трансляция на телевизор.
- **Вебинары** (1.5): регистрация на трансляцию с лимитом мест и ссылкой-приглашением, напоминания зарегистрированным, отчёт по участникам с фактическим временем присутствия.
- **«Спросите видеотеку»** (1.5): вопрос обычными словами — ответ по расшифровкам со ссылками на конкретные секунды видео.
- **Качество просмотра** (1.5): плеер измеряет время старта, паузы на подгрузку и сбои; раздел «Качество» в панели администратора с разрезами по дням, устройствам и видео.
- **Премьеры** (1.6): показ видео в назначенный час с обратным отсчётом, чатом и напоминаниями подписчикам.
- **Совместный просмотр** (1.6): комната «Смотрим вместе» с общей паузой, перемоткой и чатом.
- **Живые субтитры эфира** (1.6) и **экраны-витрины** для телевизоров в холле; **видео-SEO** для публичных роликов.
- **Итоги встречи** (1.7): по записи совещания — краткое содержание, решения и задачи с переходом к нужной секунде.
- **Автоклипы** (1.7): ИИ предлагает фрагменты для отдельных роликов; **тренажёры с ветвлением** — «выбери действие» прямо в плеере.
- **Офлайн-просмотр** (1.7): «Скачать для офлайна» и раздел «Скачанные» — видео открывается без сети.
- **Согласование видео** (1.8): отправка коллегам на проверку, замечания с привязкой к секунде, решения «принято» / «нужны правки».
- **Календарь публикаций** (1.8) и **уведомления карточкой** в Microsoft Teams, Slack и Mattermost.
- **Хранилище** (1.8): кто сколько занимает, квоты на канал, автоудаление исходников; **главы по сменам слайдов**.
- **Размытие лиц и областей в кадре** (1.9) с автопоиском лиц и **монтаж по расшифровке**: вырезать фразы и слова-паразиты.
- **Ретрансляция эфира** на VK Видео, YouTube и Rutube (1.9), **перемотка эфира назад** и просмотр с начала.
- **Витрины** — страницы-подборки со своим адресом (1.9); **сроки хранения**, архив, «не удалять» и пересмотр актуальности.
- Загрузка файлов **до 2 ТБ** с докачкой после обрыва: размер части подстраивается под файл (1.10.1).
- **Вебинары** (1.10): каталог, страница мероприятия с анкетой, внешние участники по персональной ссылке, напоминания, комната ожидания, сертификаты и отчёт.
- **Графический видеоредактор** (1.10): таймлайн с фрагментами, переходами, титрами, картинками и музыкой; сборка поверх видео или в новое.
- В эфире: **опросы**, **вопросы ведущему** с голосованием, **напоминание** о запланированном эфире и файл календаря (.ics).
- **Уведомления в Telegram** (привязка через бота) и вход через **корпоративный SSO** (OpenID Connect).
- **Подсказки и конечные заставки** в плеере (как на YouTube), **очередь просмотра**, режим **«только звук»**, **повтор чата** в записях эфиров, панель **«Текст на экране»** для видео со слайдами.
- **RSS/Atom и подкаст-ленты** каналов, категорий, плейлистов и подписок (личный токен для видео «для сотрудников»), **еженедельный дайджест** по почте.

**Для авторов (Студия)**
- Загрузка файлов до 2 ТБ с докачкой после обрыва (chunked resumable upload), перетаскиванием, несколько файлов сразу; расписание публикации.
- Доступ: **публичное** (видно без входа), **для сотрудников** (только зарегистрированным), **по ссылке**, **приватное** (выбранным пользователям и **группам**).
- **Защищённые ссылки для внешних зрителей** (партнёры, подрядчики): без учётной записи, с паролем, сроком действия, лимитом открытий, разрешением скачивания; отзыв в любой момент.
- **Обязательные просмотры**: назначить видео или плейлист сотрудникам, группам или всем — со сроком, процентом просмотра, обязательным тестом; отчёт «кто посмотрел», экспорт CSV, напоминания.
- **Кто смотрел**: поимённый список зрителей видео с процентом просмотра (включается администратором), CSV.
- **Тест внутри видео**: редактор вопросов (один/несколько ответов, таймкод, пояснение), проходной балл, результаты сотрудников.
- **Водяной знак зрителя**: имя, почта и время поверх видео (защита от утечек записей экрана).
- **Замена файла** без потери ссылки, статистики и комментариев (версии), **импорт по ссылке** (прямой файл или, при установленном yt-dlp, страница видеосервиса), **запись экрана/камеры в браузере** с загрузкой на портал.
- **Запись экрана с камерой** в четырёх вариантах: только экран, только камера, **экран + камера в углу** и **камера + экран в углу** (1.10.2). Крупный план и врезку можно **менять местами прямо во время записи** — кнопкой или клавишей `S`, без остановки и склейки. Если показ экрана завершён, запись продолжается с камеры.
- **ИИ-помощник**: по субтитрам предлагает название, описание-конспект, главы и теги (любой OpenAI-совместимый сервер: Ollama, LM Studio, vLLM, OpenAI); автор применяет выборочно.
- Редактирование: название, описание, категория, теги, обложка (своя или один из трёх автоматических кадров), главы (таймкоды в описании), субтитры (загрузка SRT/VTT или автоматическая генерация), режим комментариев, разрешение на скачивание.
- Аналитика: просмотры, время просмотра, удержание аудитории, источники, устройства, динамика по дням; статистика канала.
- Прямые трансляции: из OBS/энкодера (RTMP, SRT) или прямо из браузера (WebRTC/WHIP), чат с модерацией и баном, счётчик зрителей, автоматическая запись эфира и превращение её в обычное видео.
- **Срок публикации** (автоматическое снятие с публикации), вкладка **Материалы**, выгрузка видео **в базу знаний (RAG)** одной кнопкой; в назначениях — **контроль присутствия** («Вы смотрите?») и **сертификат**.
- В студии эфира — управление опросами и вопросами зрителей, экспорт вопросов в CSV, число подписавшихся на напоминание.
- **Редактор видео**: обрезка начала и конца, вырезание фрагментов, **удаление пауз** (как в Descript), **клип как отдельное видео** (в т. ч. вертикальный 9:16 для ленты коротких), история монтажа — файл заменяется новой версией без потери ссылки и статистики.
- **Перевод субтитров** через ИИ на другие языки, **распознавание текста на экране** (OCR, tesseract) с поиском, **подсказки и конечная заставка**, **экспорт SCORM** для LMS.

**Для администраторов**
- Регистрация по разрешённым доменам почты (задаются в панели), подтверждение e-mail, одобрение администратором (или автоодобрение для отдельных доменов), приглашения по ссылке, блокировка, роли (пользователь / модератор / администратор), сброс пароля, двухфакторная аутентификация (TOTP), API-токены.
- Вход через Active Directory / LDAP (с фильтром пользователей, обязательной и «админской» группой, **вложенными группами**); **единый вход (SSO) по OpenID Connect** (Keycloak, Entra ID/ADFS, Okta, Google, Яндекс ID) с автоодобрением и синхронизацией групп; **группы сотрудников** — вручную, по группам AD или из claim SSO.
- **Интеграции**: Telegram-бот для уведомлений; **база знаний (RAG)** — документы из видео (описание, главы, материалы, транскрипт с таймкодами) отправляются во внешний RAG-сервис (push) или забираются им по API с токеном (pull); **описание всех видео через стороннюю LLM** перед выгрузкой.
- **Домены встраивания** плеера (CSP `frame-ancestors`), настройки сертификатов, лимит размера материалов.
- **Вебхуки** (15 событий, подпись HMAC, журнал доставок и повторы), **xAPI** в LRS (completed/passed/failed), **API плеера** для встраивания (postMessage), **папка автоимпорта** на сервере, **обязательная 2FA для администраторов**.
- Модерация: премодерация новых видео, одобрение/отклонение/блокировка, жалобы, комментарии, стоп-слова, журнал действий (аудит).
- Настройки без правки файлов: брендинг (название, логотип, фавикон, цвет), регистрация и безопасность, загрузка и транскодирование (качества, пресет, аппаратное ускорение), комментарии, SMTP, LDAP, SSO, ASR, ИИ-помощник, интеграции (Telegram, RAG, вебхуки, xAPI), редактор/OCR/ленты/дайджест/автоимпорт, обучение и аналитика (сертификаты), трансляции, хранение.
- Дашборд, очередь заданий (транскодирование, субтитры, письма), состояние системы, обслуживание, объявление на весь портал.
- Резервное копирование и восстановление, обновление одной командой.

## Требования

| | Docker Compose (рекомендуется) | Нативная установка |
|---|---|---|
| ОС | Ubuntu 20.04+/22.04/24.04, Debian 11+, Rocky/Alma 8+, Fedora | Ubuntu 22.04/24.04, Debian 12 |
| CPU / RAM | 2 ядра, 4 ГБ (транскодирование — чем больше, тем быстрее) | то же |
| Диск | от 20 ГБ + место под видео | то же |
| Порты | 80, 443 (веб), 1935/tcp (RTMP), 8890/udp (SRT), 8189/udp+tcp (WebRTC) | то же |
| Домен | для Let's Encrypt — публичное DNS-имя; в закрытой сети — самоподписанный сертификат | то же |

Устанавливаются автоматически: Docker Engine + Compose (или nginx, PostgreSQL 16, Node.js 22, ffmpeg), сервер трансляций MediaMTX.

## Установка одной командой

Скопируйте папку проекта (или архив `corpvideo-<версия>.tar.gz`) на сервер и выполните от root:

```bash
tar xzf corpvideo-1.0.0.tar.gz && cd corpvideo
sudo ./install.sh
```

Скрипт задаст несколько вопросов (режим, домен, HTTPS, e-mail и пароль администратора, разрешённый домен почты) и всё сделает сам. Без вопросов:

```bash
# Docker Compose, публичный домен, Let's Encrypt
sudo ./install.sh --mode docker --domain video.company.ru --ssl letsencrypt --email it@company.ru \
     --admin-email admin@company.ru --admin-password 'СложныйПароль1' --allow-domain company.ru --yes

# Нативно, закрытая сеть, самоподписанный сертификат, обращение по IP
sudo ./install.sh --mode native --domain 10.0.0.15 --ssl selfsigned \
     --admin-email admin@company.ru --admin-password 'СложныйПароль1' --yes

# Из интернета (архив или git-репозиторий с исходниками)
curl -fsSL https://git.company.ru/corpvideo/raw/main/install.sh | sudo bash -s -- --repo https://git.company.ru/corpvideo.git --yes
```

Параметры `install.sh`:

| Параметр | Значение |
|---|---|
| `--mode docker\|native` | способ установки (по умолчанию docker) |
| `--domain HOST` | домен или IP портала |
| `--ssl letsencrypt\|selfsigned\|none\|custom` | HTTPS; `custom` — свои `fullchain.pem`/`privkey.pem` в `DATA_DIR/ssl` |
| `--email` | e-mail для Let's Encrypt |
| `--admin-email`, `--admin-password`, `--admin-name` | первый администратор |
| `--allow-domain DOMAIN` | домен почты, с которого разрешена регистрация (по умолчанию домен администратора) |
| `--data-dir DIR` | каталог данных: видео, БД (docker), сертификаты, копии (по умолчанию `/var/lib/corpvideo`) |
| `--app-dir DIR` | каталог приложения (по умолчанию `/opt/corpvideo`) |
| `--http-port`, `--https-port` | порты nginx (docker) |
| `--mediamtx-version X.Y.Z` | версия сервера трансляций |
| `--repo URL` / `--source FILE.tar.gz` | откуда взять исходники при запуске через `curl \| bash` |
| `--no-firewall` | не открывать порты в ufw/firewalld |
| `--yes` | без вопросов |

По окончании скрипт печатает адрес портала, данные администратора и подсказки. Повторный запуск `install.sh` на сервере с существующей установкой безопасен — данные и база сохраняются.

### Что делает установщик

1. Проверяет ОС, память и диск; ставит недостающие пакеты.
2. **Docker**: ставит Docker Engine и Compose, копирует проект в `/opt/corpvideo`, создаёт `.env` со случайными секретами, рендерит конфигурацию MediaMTX, получает сертификат (Let's Encrypt через certbot или самоподписанный), собирает образы `corpvideo/app` и `corpvideo/nginx`, запускает `db`, `api`, `worker`, `mediamtx`, `nginx` (и `certbot` для автопродления).
   **Нативно**: ставит nginx, PostgreSQL, Node.js 22 (NodeSource), ffmpeg; создаёт пользователя `corpvideo`, базу данных, `/etc/corpvideo/corpvideo.env`; собирает веб-интерфейс; скачивает MediaMTX; устанавливает службы systemd `corpvideo-api`, `corpvideo-worker`, `corpvideo-mediamtx`; настраивает сайт nginx с HTTPS.
3. Применяет миграции БД, создаёт администратора, разрешает домен почты.
4. Устанавливает утилиту `corpvideo` и открывает порты в файрволе.
5. При ошибке — откат с сохранением данных; подробный журнал в `/var/log/corpvideo/install.log`.

## Управление

```bash
corpvideo status            # состояние служб, версия, место на диске, статистика
corpvideo logs [api|worker|mediamtx|nginx|db]
corpvideo restart | stop | start
corpvideo update            # обновление (из папки с новой версией: sudo ./update.sh)
corpvideo backup [--media] [--keep 14] [--dest /mnt/backup]
corpvideo restore /var/lib/corpvideo/backups/<дата>
corpvideo uninstall [--purge] [--backup]
corpvideo cli <команда>     # консольные команды приложения (см. ниже)
corpvideo ports             # какие порты должны быть открыты
```

Консольные команды приложения (`corpvideo cli …`): `create-admin`, `set-password`, `set-role`, `approve`, `add-domain`, `list-domains`, `list-users`, `settings get|set`, `status`, `reindex`, `recompute-storage`, `retry-failed`, `maintenance`.

### Обновление

Распакуйте новую версию рядом и запустите из неё `sudo ./update.sh` (или `corpvideo update --source corpvideo-1.3.1.tar.gz`, либо `--repo URL`). Скрипт делает дамп базы в `DATA_DIR/backups/pre-update-*.dump`, копирует файлы, пересобирает образы / зависимости, применяет миграции, перезапускает службы и обновляет конфигурацию nginx и MediaMTX. Конфигурация (`.env`) и данные не затрагиваются.

### Резервное копирование

`corpvideo backup` сохраняет дамп PostgreSQL и конфигурацию в `DATA_DIR/backups/<дата>/`, с `--media` — ещё и архив всех видео. Для регулярных копий: `0 3 * * * /usr/local/bin/corpvideo backup --keep 14` в crontab. Восстановление: `corpvideo restore <каталог копии или db.dump>`.

### Удаление

`sudo ./uninstall.sh` останавливает и удаляет приложение, **сохраняя** данные и базу; `--purge` удаляет всё (видео, БД, сертификаты, конфигурацию); `--backup` перед удалением делает копию в `/root`.

## Архитектура

```
 браузер / OBS ──HTTPS──▶ nginx ──▶ Node.js API (Fastify)  ──▶ PostgreSQL 16
                          │  │           │  ▲                    (данные, поиск, очередь заданий)
                          │  │           │  └── LISTEN/NOTIFY ──▶ воркер (ffmpeg: HLS-лестница, миниатюры,
                          │  │           ▼                         раскадровка, субтитры ASR, письма, обслуживание)
                          │  └─ /media/* ──auth_request──▶ файлы: DATA_DIR/media (HLS, mp4, обложки)
                          └─ RTMP/SRT/WHIP ──▶ MediaMTX ──HLS──▶ API-прокси ──▶ зрители; запись ──▶ импорт в видео
```

- **server/** — Node.js 22 (ESM), Fastify 5, `pg` без ORM (SQL-миграции в `server/src/migrations`), очередь заданий в PostgreSQL (`SKIP LOCKED`), шина событий `LISTEN/NOTIFY`, WebSocket-хаб (уведомления, прогресс обработки, live-чат), сессии в БД, scrypt-пароли, TOTP, LDAP (`ldapts`), почта (`nodemailer`).
- **web/** — Vue 3 + Vite + Pinia, hls.js, собственный плеер, дизайн-токены в CSS-переменных (светлая/тёмная тема).
- **deploy/** — Dockerfile (многоступенчатый: сборка веб, зависимости, образ приложения, образ nginx), шаблоны nginx и MediaMTX, unit-файлы systemd, пример `.env`.
- **scripts/** — библиотека установщика (`lib/common.sh`), сценарии `install-docker.sh` / `install-native.sh`, утилита `corpvideo`.
- Раздача медиа: nginx отдаёт файлы напрямую (sendfile, Range), проверяя права через подзапрос к API (`auth_request`); скачивание оригинала — через `X-Accel-Redirect`.
- Видео транскодируется в HLS одной командой ffmpeg (несколько качеств сразу, до 2160p, фрагменты 6 с), дополнительно — прогрессивный mp4 до 720p, три автоматических кадра для обложки, раскадровка (спрайты + VTT).

## Прямые трансляции

- В студии автор создаёт трансляцию и получает **ключ** и адреса: `rtmp://<домен>:1935/live` + ключ (OBS: Настройки → Вещание → Другой сервис), `srt://<домен>:8890?streamid=publish:live/<ключ>`, либо кнопка «Эфир из браузера» (камера/экран, WebRTC/WHIP — требует HTTPS).
- Ключ проверяется MediaMTX через хук API; зрители получают HLS через API-прокси (ключ не раскрывается, права проверяются).
- Запись эфира (если включена) после завершения автоматически становится видео на канале автора и проходит обычную обработку.
- Чат хранится в базе; автор и модераторы могут удалять сообщения и банить участников.

## Вход через Active Directory / LDAP

Панель → Настройки → LDAP: адрес (`ldap://` или `ldaps://`), учётная запись для поиска (bind DN и пароль), база поиска, фильтр (по умолчанию `sAMAccountName`, `userPrincipalName` или `mail`), атрибуты e-mail и имени, группа, обязательная для входа, и группа администраторов. Кнопки «Проверить подключение» и «Проверить вход» позволяют убедиться в настройках. Пользователи AD создаются при первом входе (с автоодобрением, если включено) и не могут менять пароль в портале.

## Автосубтитры (ASR)

Портал отправляет аудиодорожку на любой сервер с API, совместимым с OpenAI `/v1/audio/transcriptions` (например, `faster-whisper-server`, `whisper.cpp server`, `vLLM`), и сохраняет результат как субтитры VTT. Настройки → Автосубтитры: адрес, ключ, модель, язык, автоматическая генерация для всех новых видео. Пример запуска сервера в той же сети: `docker run -p 8000:8000 fedirz/faster-whisper-server:latest-cpu`.

## ИИ-помощник

Настройки → ИИ-помощник: адрес любого сервера с API `POST /v1/chat/completions` (Ollama `http://host:11434/v1/chat/completions`, LM Studio, vLLM, OpenAI), ключ, модель. По транскрипту (субтитрам) модель предлагает название, описание-конспект, главы и теги — автор видит подсказки в студии и применяет их выборочно; можно включить автоматическую подготовку подсказок после автосубтитров. Данные не покидают контур компании, если сервер развёрнут локально. Пример: `docker run -d -p 11434:11434 ollama/ollama && docker exec -it <id> ollama pull qwen2.5:7b`.

## Обязательные просмотры, группы, тесты

- **Группы сотрудников** (Администрирование → Группы): вручную (по e-mail, списком) или из Active Directory — укажите DN группы AD, и состав будет обновляться при каждом входе сотрудника через LDAP. Группам можно выдавать доступ к приватным видео и назначать просмотры.
- **Назначить к просмотру** — кнопка в студии видео, на странице видео (меню «⋯») и в разделе «Студия → Обязательные просмотры». Адресаты: сотрудники, группы или все. Параметры: срок, процент просмотра для зачёта, обязательный тест, напоминание за N дней. Отчёт «кто посмотрел» с фильтрами и экспортом CSV, кнопка «Напомнить не выполнившим». Кто может назначать — настраивается (только модераторы или все сотрудники).
- **Тест** (Студия → видео → Тест): вопросы с одним или несколькими правильными ответами, таймкод (вопрос ставит видео на паузу) или итоговый тест после просмотра, проходной балл, показ правильных ответов, повторные попытки; результаты по сотрудникам и CSV.
- **Защищённые ссылки** (Студия → видео → Доступ, или «Поделиться → Гостевая ссылка»): `https://портал/s/<токен>`, пароль, срок, лимит открытий, скачивание. Гость видит только это видео.

## Единый вход (SSO), Telegram, база знаний (RAG) — версия 1.2

- **SSO по OpenID Connect** (Настройки → Единый вход): издатель (issuer), Client ID/Secret, scopes, claims для почты, имени и групп, автоодобрение, проверка домена, «админская» и обязательная группы, синхронизация групп, режим «только SSO». Адрес обратного вызова у провайдера: `https://портал/api/auth/oidc/callback`. Поток Authorization Code + PKCE, проверка подписи ID-токена по JWKS.
- **Telegram** (Настройки → Интеграции): токен бота от @BotFather, «Сохранить и проверить»; сотрудник привязывает аккаунт в своих настройках (ссылка на бота с кодом, `/start <код>`). Воркер получает сообщения по long polling — внешний адрес не нужен.
- **База знаний (RAG)** (Настройки → Интеграции): портал строит из каждого видео документ (Markdown + JSON: название, описание или ИИ-конспект, главы, материалы, транскрипт со ссылками на таймкоды) и **отправляет** его на указанный адрес (`json` — `POST {id,title,url,text,source,metadata}`; `markdown` — multipart с файлом `.md`) автоматически после обработки и субтитров, либо RAG-система **забирает** документы сама: `GET /api/rag/documents?since=…` и `GET /api/rag/documents/:id[?format=markdown]` с заголовком `Authorization: Bearer <токен выгрузки>`. Опция **«Описывать видео через ИИ перед выгрузкой»** и кнопка **«Описать все видео»** заполняют пустые описания, главы и теги через настроенную LLM (ИИ-помощник); состояние выгрузки видно в панели и в студии.
- **Срок публикации** видео и **домены встраивания** (Настройки → Общие), **материалы к видео** (до 200 МБ, настраивается), **сертификаты** (Настройки → Обучение и аналитика: подписант, формулировка), **вложенные группы AD** (Настройки → LDAP).

- **Перевод субтитров** (вкладка «Субтитры», нужен ИИ-помощник) и **текст на экране** (OCR через `tesseract`; Настройки → Редактор, OCR, ленты; панель «Текст на экране» и поиск).
- **Подсказки и конечные заставки** (вкладка «Подсказки»), **повтор чата эфира**, **очередь просмотра**, **«только звук»** (аудиодорожка m4a создаётся при обработке).
- **RSS/Atom и подкасты**: `/api/rss/latest`, `/api/rss/channel/<handle>`, `/api/rss/category/<slug>`, `/api/rss/tag/<тег>`, `/api/rss/playlist/<id>`, `/api/rss/subscriptions` (`?format=atom`, `?audio=1`, личный токен `?ft=` из Настройки → Токены API).
- **Дайджест** (день/час, отключается сотрудником), **папка автоимпорта** (каталог на сервере, владелец, видимость, журнал), **обязательная 2FA для администраторов** (Настройки → Регистрация и безопасность).

## Премьеры, совместный просмотр, экраны и живые субтитры — версия 1.6

- **Тренажёр с ветвлением** (Студия → видео → Тренажёр): развилки по таймкодам, до шести вариантов, переход к нужной секунде, разбор выбора и финальные ветки. Зритель видит выбор прямо в плеере, автор — отчёт по развилкам (`scenario.enabled`).
- Маршруты `/api/videos/:id/meeting-notes` (+`/export`), `/api/videos/:id/clip-suggestions`, `/api/videos/:id/scenario` (+`/choice`, `/report`).

Замечания пишутся к текущей секунде и открывают запись на этом месте; автор отмечает исправленные. Рецензент решает — «согласовать» или «вернуть на доработку» (с пояснением). ## Размытие, монтаж по тексту, ретрансляция и сроки хранения — версия 1.9

- **Размытие лиц и областей** (Студия → видео → Размытие): рамка рисуется мышью прямо на кадре, у каждой — свой отрезок времени и сила размытия; кнопка «Найти лица» предлагает готовые рамки (нужен пакет `python3-opencv`). Видео пересобирается, ссылка и статистика сохраняются (`editor.blur_enabled`).
- **Монтаж по расшифровке** (Студия → видео → Монтаж по тексту): отметил лишние фразы — портал вырезал их и пересчитал главы, подсказки и метки. Кнопка «Найти слова-паразиты» находит «э-э», «ну», «как бы», «вот», «типа» с контекстом; словарь настраивается (`editor.text_edit`, `editor.filler_words`).
- **Ретрансляция эфира** (Студия → трансляция → Ретрансляция): площадки VK Видео, YouTube, Rutube или свой RTMP/SRT с адресом и ключом. Запускается сама вместе с эфиром, поток уходит без перекодирования, состояние каждой площадки видно отдельно (`live.restream_enabled`).

- **Витрины** (Администрирование → Витрины): страница-подборка со своим адресом `/hub/<адрес>`, обложкой и разделами (выбранные видео, плейлист, категория, тег, свежие). Закрепляется в меню портала (`showcases.enabled`).
- **Сроки хранения** (Администрирование → Хранение): правила «через N дней — в архив, в корзину или уведомить автора», предпросмотр, предупреждение автору, журнал с CSV. **Архив** убирает видео из каталога, сохраняя его у автора; **отметка «не удалять»** выводит видео из-под правил; **«актуально до»** напоминает пересмотреть материал (`lifecycle.enabled`).
- Маршруты `/api/videos/:id/editor/blur|faces|frame|transcript|fillers|text-cut`, `/api/studio/live/:id/restreams`, `/api/live/:id/dvr` (+`/play`), `/api/showcases`, `/api/admin/showcases`, `/api/admin/retention`, `/api/admin/lifecycle/videos`.

## Почта (SMTP)

Письма подтверждения адреса, одобрения регистрации, сброса пароля, приглашения, уведомления администраторов о новых регистрациях, уведомления о новых видео и ответах. ## API

Все функции интерфейса доступны через JSON API (`/api/...`). Для интеграций пользователь создаёт токен в «Настройки → API-токены» и передаёт его в заголовке `Authorization: Bearer cv_…`. Токен даёт права загрузки и чтения от имени владельца; раздел администрирования (`/api/admin/...`) по токену недоступен — для него нужен вход по паролю.

```bash
# загрузка видео одним запросом
curl -H "Authorization: Bearer cv_XXXX" -F file=@lecture.mp4 -F title="Лекция" -F visibility=internal \
     https://video.company.ru/api/uploads/simple
# список последних видео, поиск
curl https://video.company.ru/api/feed/latest
curl "https://video.company.ru/api/search?q=насос"
```

Встраивание: `<iframe src="https://video.company.ru/embed/<id>" allowfullscreen></iframe>` (для видео «для сотрудников» зритель должен быть авторизован в портале); oEmbed — `/api/oembed?url=…`.

## Разработка

```bash
# PostgreSQL 16 с расширениями citext, unaccent, pg_trgm; создайте БД и пользователя corpvideo
cd server && cp ../deploy/env.example .env   # отредактируйте DATABASE_URL, DATA_DIR, BASE_URL=http://localhost:3000, NODE_ENV=development
npm ci && npm run migrate && node src/cli.js create-admin --email admin@example.com --password 'Admin12345'
npm start          # API на :3000 (раздаёт web/dist, если собран)
npm run worker     # воркер обработки (нужен ffmpeg)
cd ../web && npm ci && npm run dev   # Vite на :5173 с прокси на :3000
npm test           # интеграционные тесты API (server/)
```

## Шрифты и брендинг

Логотип, цвета и фирменный шрифт заголовков **DIN Condensed** (файлы Light и Regular из `web/public/fonts/DINCondensed/`) взяты с vodokomfort.ru; если файлы шрифта удалить, заголовки автоматически переключатся на свободный аналог Oswald. Название, логотип, фавикон и акцентный цвет меняются в панели администратора без пересборки.
